---
name: add-service
description: Scaffold a new service in services/ with index.js, a test file, and a README. Use when the user asks to create or add a new service.
---

1. Create services/<name>/index.js with ES module exports.
2. Create services/<name>/index.test.js with at least one passing test.
3. Create services/<name>/README.md describing the service's purpose.
4. Run `npm test` and confirm it passes before reporting done.
